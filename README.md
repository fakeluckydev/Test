# Веб-открытка "С Днём Рождения, Любовь!"

## О проекте

Это простой, но элегантный одностраничный сайт-открытка, созданный в качестве подарка на 18-летие. Дизайн выполнен в нежных тонах, с красивым цветочным фоном и анимациями, чтобы создать праздничное настроение.

## Как посмотреть

1.  Скачайте файлы проекта (`index.html` и `style.css`) из этого репозитория.
2.  Откройте файл `index.html` в любом современном веб-браузере (например, Chrome, Firefox, Safari, Edge).

Для корректного отображения шрифтов и фона требуется подключение к Интернету.

## Технологии

*   **HTML5** - для структуры страницы.
*   **CSS3** - для стилизации, включая:
    *   Flexbox для центрирования.
    *   Google Fonts для подключения кастомных шрифтов (`Pacifico` и `Roboto`).
    *   CSS Animations (`@keyframes`) для плавного появления и пульсации элементов.
    *   `backdrop-filter` для создания эффекта "матового стекла".

## Дизайн

Основная идея заключалась в создании легкой, воздушной и романтичной атмосферы, соответствующей поводу — 18-летию девушки по имени Любовь. Фоновое изображение с цветами и розовая цветовая гамма поддерживают эту тему.
